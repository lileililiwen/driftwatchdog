## Approach
- Quality: `workspace.lints` (`clippy::all,pedantic`-subset + `deny warnings` in CI), `rust-version = "1.7x"` after probing MSRV, `cargo-deny` for advisories/licenses, `llvm-cov` or `tarpaulin` threshold on changed crates, `proptest` for normalizer (arbitrary unicode, never-panic + idempotence `normalize(normalize(x))==normalize(x)` where applicable).
- CI: `cargo clippy --workspace --all-targets --all-features -- -D warnings`; add `macos-14` + arm64 job (or `macos-latest`), `shellcheck scripts/*.sh`, `npm audit --omit=dev` (or `npm audit signatures`), `sh scripts/smoke.sh` gated behind a label or nightly to keep PRs fast.
- Release: `permissions: id-token: write` on npm-publish; refresh `macos-13→14/15`; `scripts/version.sh` asserts `Cargo.toml == tag`; auto-tag requires `REPO_PAT` else skip with notice + `--dry-run` default on PRs; cold-start bump creates `v0.1.0`; Dependabot (cargo+npm+actions weekly); SBOM via `cargo-sbom`/`syft` attached to release (signing: document checksums-only + future cosign, or add `sigstore` if cheap).
- Docs/UX: naming rule — binary is `driftwatchdog` from cargo/direct, `driftwatch` via npm launcher; fix README install line + npm section + examples; fill `release-distribution` Purpose; sync HANDOFF/AGENTS close steps; add `driftwatch.toml.example` + minimal checker copy-paste; installer suggests `cargo install --locked` on unsupported hosts and documents `--dry-run`; npm `os/cpu` narrowed or preflight error for `darwin-arm64`; `clap` `long_about` + per-subcommand examples, `clap_complete` + man generation; error type carries `hint` field rendered as `hint: try …`; doctor `INFO` level for unconfigured-but-ok states.

## Non-goals
- No Windows/musl support expansion (messaging only); no new product features.
